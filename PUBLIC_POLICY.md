# What is public and what is not

## Public (AGPL-3.0 for software, CERN-OHL-S v2 for designs; see the README)

- Source code: simulation, control scripts, firmware, vision.
- CAD files and print settings.
- Videos, logs and results from Phases 0-2.
- Technical decisions (simulator, mechanics, electronics) and their justification.
- Safety design of the hardware (emergency stop, limits, watchdog).

## Not public

- Anything about Phase 3: protocols, drafts, correspondence with institutions, committee submissions and their outcomes.
- Personal data of collaborators, unless they agree to be named.
- Purchase receipts, addresses and account details.
- Credentials, tokens and API keys. Never commit them.

## Rules for contributors

1. Before publishing a result, check it does not reveal anything from the "not public" list.
2. Phase 3 material lives in a private space, never in this repository or its history.
3. If you are unsure whether something is public, ask the project owner first.
4. Content that reached the public history by mistake is reported immediately so it can be removed.
