# Brand: Vernier

Working name of the project (formerly "Monkey with a Scalpel"). A vernier scale reads between the marks of the main ruler: two scales with
slightly different pitch, and the one pair of marks that line up gives the fraction. That is what the project does with cameras and a closed
loop: it reads finer than the mechanics resolve, and a person approves every step.

**Slogan:** *Read finer than the ruler.*
**Descriptor:** an open robotic lab assistant with an LLM copilot and a human who approves every step.

## Files

| File | Use |
|---|---|
| `wordmark-light.png`, `wordmark-dark.png`, `wordmark-glow.png` | The wordmark on light, on dark and the version with glow on deep space |
| `wordmark-light.svg`, `wordmark-dark.svg` | Vector wordmark (the text depends on the viewer's font; use the PNG when the exact letters matter) |
| `icon.svg`, `icon-{512,256,180,64}.png` | The I alone on a tile: avatar and app icon |
| `favicon.svg`, `favicon-{16,32,48}.png` | The I alone, simplified: browser tab |
| `social-preview.png` | 1280 x 640, the image shown when the repository is shared (set in the repository settings) |

The **I** is the mark: a bar and a dot, the aligned tick of a vernier. At small sizes only the I is used.
